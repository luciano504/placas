# Placas de Oferta — Rende Mais Supermercados

Aplicativo para as lojas gerarem as placas de preço da promoção semanal (formato "de/por"), com escolha de tamanho (A2, A3, A4, A5) e quantidade, agrupadas em um único PDF otimizado para impressão.

**Acesso:** https://luciano504.github.io/placas/

A cada semana o arquivo `index.html` é substituído pela versão com as novas ofertas embutidas.
